# 语言特色与正文标点

## 参照对象与证据边界

本文件把已读论文的表达功能和用户指定的成稿偏好结合起来。语料中的显式转折、操作动词、功能性命名可作为写作参照。无破折号、无冒号等规则来自用户要求，不是作者身份特征，也不能用于判断文本是否由 AI 生成。主要来源和例外见 [style-profile.md](style-profile.md) 与 [evidence-map.md](evidence-map.md)。

## 需要迁移的语言特色

| 层面 | 写法选择 | 依据与实施边界 |
|---|---|---|
| 问题表达 | 由具体失败条件走到机制性不足，说明为何需要当前设计 | GBM、PPO、PPD、PromptPilot 的引言推进，不套固定开头 |
| 句子主干 | 让模块、表示、策略或实验作主语，使用明确操作动词 | construct、represent、refine、align、coordinate 等须对应真实运算 |
| 逻辑推进 | 每次转折都增加具体信息，先写上一环节留下的问题，再写下一步 | GBM 的前向匹配、反向匹配与采样体现这种关系 |
| 模块命名 | 名称提示其操作对象和职责，正文、公式、图表名称统一 | 迁移功能性命名，不为模仿强造缩写 |
| 段落组织 | 首句给本段判断，中间给机制或证据，末句说明得到的能力或下一步 | 编辑实施方式，不要求每段相同句数或相同末句模板 |
| 技术细节 | 一句优先承载一个主要判断，明确输入、操作、输出及阶段 | 确有从属条件可用从句，不把完整流程堆成一个超长句 |
| 贡献表达 | 问题表述、机制与经验证实的能力相互区分 | 数量随内容变化，不固定三条，不只堆叠模块 |
| 结果表达 | 报关键对比和条件，再解释与设计诉求的关系 | 不逐格复述表格，也不把平均优势写成逐项全优 |
| 语态与时态 | 介绍本方法可用主动句，过程说明可用被动句，已完成实验按事实表达 | PPO、PPD 与 PromptPilot 的语态不同，不设单一作者句法 |
| 术语与力度 | 同一术语含义稳定，能力标签绑定训练、数据与推理条件 | 不因风格需要新增 first、universal 或 significant |

中文解释用直接的因果和操作表述，少写“协同赋能”“全面提升”等空泛词。英文正文保留自然的学术语法，不把每段都改成同一个 We propose 或 To address 模板。

## 用户指定的标点规则

默认作用于新生成或改写的题目、摘要、正文、贡献项及图注。参考文献的准确题名、原文直接引语、官方规定的固定标题和必须原样保留的材料不强行修改。用户后来有特定格式要求时以其新指示为准。

- 不用中文破折号和英文 em dash。也不用 en dash 或两个连续连字符代替插话式破折号。数值范围在自然语言中写成“至”或英文 to，参考文献页码范围按格式保留。
- 不用中文或英文冒号引出解释、列表、贡献和结论。改成完整陈述句、从句或单独段落。标题中的方法名与副标题可改为自然的 for 或 with 结构，不用冒号拼接。
- 默认不用分号连接多个独立判断，拆成句子或用准确连词。
- 少用括号插入第二条论证，重要信息写入正文。首次定义缩写、公式编号、标准作者年份引用及必要统计报告可保留括号。
- 不用斜杠堆叠可用自然语言说清的关系。训练与推理、特征与空间等关系应写成完整词组。斜杠属于单位、路径或数学运算时保留。
- 不在正文使用箭头链、加号链、竖线或装饰性强调符号替代论证。公式和真实算法记号照常保留。

合法例外包括数学中的比例及集合符号、向量或矩阵记号、代码和路径、URL 的协议符号、DOI、参考文献、精确引用及会议要求的固定格式。英文复合词如 task-specific 的普通连字符可以保留。不要为了遵守正文标点规则破坏 YAML、LaTeX 命令、代码或题录。

## 用完整句法代替符号拼接

以下均为原创示例，不是作者原句。

| 原句的问题 | 建议写法 |
|---|---|
| 用冒号宣布解决办法 | To reduce sensitivity to initialization, we refine the prompt distribution using feedback from the segmentation model. |
| 用破折号插入解释 | The defender suppresses disruptive prompts during inference. This operation retains the frozen segmentation model. |
| 用分号堆两个结果 | The model improves accuracy under the evaluated compression budgets. Its inference cost remains within the reported range. |
| 用斜杠合并不同阶段 | We describe training and inference separately because they use different inputs. |
| 用箭头代替方法说明 | The encoder extracts patch features, which are used to construct the graph. The policy then updates the prompt set. |

示例中的方法和结果只有在用户提供相应事实时才能用于真实稿件。标点修改不能改变论证关系，例如把原本的条件误改成因果，或把两个不同限制删成一个。

## 与末行优化协同

先形成自然、准确的句子，再检查编译后的段落末行。为收回一两个溢出词，可删除重复表达或改写局部词组。为延长过短末行，可补清必要对象或条件。不添加无内容的总结句，也不删去范围限定来让末行更长。

若用户只给纯文本，完成句法与标点检查即可，并说明行宽需在目标模板中验证。正文禁止标点检查应排除公式、网址、代码、参考文献及直接引语，不能对整个文件做盲目替换。
