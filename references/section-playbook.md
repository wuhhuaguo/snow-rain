# 各节写作与布局

本文件把语料观察转换为可执行写作选择。标为“建议”的长度或流程是编辑建议，不是从所有论文统计出的作者习惯。期刊格式、用户指定内容与实际证据优先。

写全文前同时使用 [page-budget.md](page-budget.md) 分配各节篇幅与起始页，并将图表计入章节空间。语言落笔及交付前检查使用 [language-guide.md](language-guide.md)，执行正文无破折号、无冒号等用户要求。写作逻辑与页面预算共同迭代，不在没有实际编译结果时承诺某一段恰好落在哪一页。

## 题目

**观察。** GBMSeg、PPO、MSMTSeg、D4PM、PromptPilot 等采用方法名或缩写加解释性副标题；IFP 的名称直接呈现概念顺序；临床与部分应用论文使用说明性长标题。

**写作选择。** 从三种结构中按研究性质选，不强制创造缩写：

- 方法名称：解决的具体任务或关键机制。
- 关键机制 for 具体任务。
- 临床问题／干预与研究对象，必要时附研究设计。

标题保留最有区分度的信息，避免把所有模块、数据集与形容词塞进去。training-free、one-shot、generalizable 只有在全文实验和协议支持时使用。标题中的核心概念应在摘要、引言、方法与实验中保持同一含义。

## 摘要

### 算法论文的功能顺序

1. 用一个具体任务或使用情境打开，而不是先讲 AI 的时代价值。
2. 指出现有路径在此情境下的关键缺口。
3. 给出方法名称与所作的问题重构／主要思路。
4. 用少量句子说明实际机制及其分工。
5. 概括实验范围和最有支持力的结果。
6. 若篇幅允许，收束到这项能力的实际含义。

**语料差异。** GBM 摘要含数据规模、DSC 数字与未来工作；PPO 摘要更详细介绍图环境、强化学习、实验类型与使用方式；PPD 强调攻防训练和只部署防御者；PromptPilot 压缩为多目标冲突与分层 agent 处理。不能据此要求所有摘要报数字、写未来工作或列三模块。

**执行建议。** 用户有字数要求时先满足要求。没有要求可先写一段紧凑摘要；决定每句话承担哪项功能，再调整字数。若没有已完成实验，最后一句写明确标记的待补结果，不写“实验表明”。用户要研究构想时用计划时态，不能伪装成完成研究。

### 临床摘要

参考 RA 的结构式摘要，保留 Background、Methods、Results、Conclusion 或目标期刊规定的标题。清楚说明设计、样本、干预／暴露、主要终点、效应及不确定性。计算机视觉摘要中的模型缩写与贡献清单不替代这些内容。

## 引言

### 标准论证链

**A. 任务与代价。** 研究对象是什么，为什么这项任务难以规模化完成？医学应用中可谈专家标注或病理图像尺度；通用视觉中可谈逐任务训练或人工提示。只保留能解释后文设计约束的背景。

**B. 可用基础与尚未解决的问题。** 交代现有范式已经做到什么，再指出在本课题条件下剩余的限制。引用文献支撑具体判断，不把同类方法全部说成无效。

**C. 缺口的机制化。** 让读者看到问题如何发生。PPO 在这里把有效提示的需求拆为语义关系与空间分布；PromptPilot 进一步拆出目标冲突、反馈错配和贡献分配。

**D. 用户的解决思路。** 用一句核心主张引入方法，再按设计要求说明关键机制。暂不展开实现超参数。

**E. 证据预告与贡献。** 只概括已完成实验所支持的能力。贡献列表是否需要、几条、是否单列，由材料与篇幅决定。

这五个功能可以跨多个段落，也可合并，不能生硬规定为五段。

### 引言常见修复

| 原稿问题 | 修复方式 |
|---|---|
| 背景过长，核心缺口出现太晚 | 保留决定数据、监督或部署条件的背景，提前引入失败现象 |
| 方法突然出现 | 在其之前写清“一个合理解法必须满足什么” |
| 引言是 Related Work 的长名单 | 按范式和约束比较，每组最后回扣当前问题 |
| 贡献清单堆模块 | 说明各机制分别解决哪项缺口，并合并重复贡献 |
| 只说泛化强 | 写明跨什么数据、任务、类别或提示条件评估 |
| 自家前作被描述得与引用原文矛盾 | 核对版本、训练协议与实验条件；以准确比较为准 |

**边界。** 原论文对前作的概括不自动成为已验证事实。涉及某基线是否使用监督、是否训练或是否利用反馈，需核对该基线对应版本；风格参考不能代替技术查证。

## 相关工作

**观察。** PPO、PPD 有独立章节。GBM、IFP、PromptPilot 则在紧凑结构中将相关脉络并入引言，不能规定必须单列。

独立章节适合文献脉络较多、期刊篇幅充分或需要清楚区分范式的情况。每一小节围绕一个与当前设计相关的分类轴，写成：

> 这一类方法依赖什么信息／假设 → 代表工作如何实现 → 在本研究情境中尚缺什么 → 当前工作在哪一处推进。

避免逐篇“某某提出……”而无比较，也不要在每一小节结尾重复整套方法。没有核实的参考文献用清楚的待补标记；不制造真实 DOI 或作者。

## 方法

### 总览段

先让读者能画出流程，再看公式：

> 给定哪些输入和监督，方法建立什么中间表示，哪些机制按什么顺序作用，如何形成最终预测；训练与推理分别使用哪些部分。

GBM 以参考图和目标图开头；PPO 交代距离矩阵、图环境和策略；PPD 把真值初始化限定在训练环境、推理只保留防御者；PromptPilot 总览说明两个 actor 与 manager 的协调。迁移到剪枝时，应明确原始模型、候选子网／掩码、教师信息、更新对象与最终部署模型，不能沿用提示图的名词。

### 小节安排

优先沿信息流或依赖关系排序：任务与符号 → 整体框架 → 关键表示／环境 → 核心机制 → 训练目标与更新 → 推理。不是每项都必须独立成节。短稿可把符号嵌入正文；符号很多的长稿可设汇总表，如 DSAGL。

每个重要机制应能回答：

- 为什么上一环节不足？
- 它接受和输出什么？
- 运算、约束、目标或更新如何执行？
- 它与总目标的联系是什么？

不要为了形式统一给现成模块另造名字。公式服务于定义和复现；未使用的符号、无实际推导价值的“理论化”包装应删去。

### 训练／推理声明

把以下四个维度分开写：

| 维度 | 需明确的事实 |
|---|---|
| 基础模型 | 是否冻结，哪些参数更新 |
| 附加模块 | 优化器、投影头、学生等是否经过训练 |
| 新任务适配 | 是否额外训练、用多少标注、是否使用参考样本 |
| 推理输入 | 是否需要类别、参考图、教师、真值或外部检索 |

“推理时无参数更新”不等于“所有模块从未训练”；“无新增标注”也不等于“无监督”。这是根据语料中不同方法协议作的准确性约束，而非为所有方法套一个能力标签。

## 实验

先写本节要验证的核心主张，再决定组织。用户有完整实验时做选择和编排；用户尚未实验时产出建议清单，不能混作实验结果。

### 复现条件

按需要交代数据来源、划分单位、预处理、监督预算、基线配置、指标、实现和计算条件。医学图像中患者／切片／patch 划分、弱监督中 bag／instance 标签、剪枝中压缩预算与恢复训练预算，都是比较是否成立的前提。

### 证据编排

| 论证问题 | 可选证据 | 文字应解释什么 |
|---|---|---|
| 方法是否有用？ | 同协议整体比较 | 相对最相关基线的主要变化与适用条件 |
| 设计为什么有用？ | 去除／替换机制、目标变化 | 变化是否与设计要求一致，是否有替代解释 |
| 能否迁移？ | 跨域、跨任务、不同初始条件 | 哪些部分固定，哪些条件变化，是否重训 |
| 代价是否合理？ | 时延、显存、调用次数、参数量等 | 与谁在什么环境下比较，额外开销从何而来 |
| 具体改进了什么？ | 定性案例、局部指标、分组结果 | 与原始失败现象对应的可见改善及例外 |

**排列没有唯一答案。** PPO 与 PPD 均较早安排消融，PromptPilot 先做整体比较；GBM 是实现／数据后消融再比较。用读者理解依赖决定顺序，不能把“消融一定在最后”写成作者习惯。

### 结果段落

采用“本段要验证的判断 → 表／图中关键证据 → 与机制相联系的解释 → 必要范围”即可。不要照读每一行。结果并非所有指标最优时，陈述实际获得的优势；不把平均改进写成逐数据集全面领先。

检查百分比点与相对百分比、DSC 与 mIoU、理论计算量与实测时延、训练耗时与推理耗时。数值提升不能自动写成 statistically significant；显著性需要相应分析。

## 讨论与结论

**观察。** DSAGL 单列 Discussion；BI-Cap 有 Conclusion and Limitation；PPD 正式版有局限；GBM 简洁收束并提出后续病理测量。没有统一的章节数量或是否写局限的规则。

结论优先回扣：原来哪项能力受到什么约束，本工作怎样改变它，最重要的结果支持了什么。不要只重复模块列表，也不引入未报告的新数字。

讨论应解释工作带来的认识、证据的适用范围、局限与合理下一步。局限具体到数据范围、初始条件、监督、计算或协议。未来工作从这些边界出发。临床应用潜力与经过临床验证的部署能力要区分。

## 三种可选全文布局

下面是根据已读稿件归纳的选择，不是投稿模板。

| 场景 | 参照布局 | 来源与例外 |
|---|---|---|
| 常规视觉方法论文 | Introduction → Related Work → Method → Experiments → Conclusion | PPO、PPD；会议要求可能不同 |
| 紧凑方法／医学会议稿 | Introduction（含相关脉络）→ Method → Experimental Results → Conclusion | GBM、IFP；PromptPilot 也无独立 Related Work |
| 细致的长篇期刊稿 | Introduction → Related Work → Method → Experiments and Results → Discussion → Conclusion | DSAGL v3；不能套到所有期刊 |

临床研究与综述不在这三种算法布局中机械选取。
