# 页数预算与成稿排版

## 规则来源

写满会议页数、段末行尽量饱满、不留一两个字或词单独成行，是本用户指定的成稿标准。下面的百分比和页数预算是实施建议。章节起始页案例来自已读版本，不代表作者所有论文都采用相同布局。

## 先确定页数怎样计算

从用户材料或该届官方要求确认正文页数上限、参考文献是否计入、附录及补充材料安排、必需声明是否计入、单栏或双栏、审稿版或终稿、作者信息占位。不要把上一届规则或另一篇录用稿的页数当作本稿规则。

尚未确定会议时可以采用下列明确标注假设的方案，不为普通写作暂停工作。开始做最终排版前必须有确定的模板和计页规则。

页数预算包含正文、图表、图注、公式和小节标题占用的空间。表中的页数是整页等价空间，双栏的一栏约等于半页，不是纯文字页数。标题和摘要在常规双栏版式中的空间会随模板变化。不要把总页数直接换成一个固定英文词数。

## 默认预算方案

以下方案是便于开写和迭代的基线，必须随贡献、图表和会议规则调整。页码表示预计位置，不是强制分页点，不插入硬分页命令来追求表格一致。

### 8 页双栏正文，参考文献另计

| 部分 | 预算页数 | 预计位置与起点 |
|---|---:|---|
| 标题、作者占位与摘要 | 0.50 | 第 1 页上部 |
| Introduction | 1.25 | 第 1 页开始，第 2 页结束 |
| Related Work | 0.75 | 第 2 页后段开始，第 3 页前段结束 |
| Method | 2.50 | 第 3 页中部开始，至第 5 页末 |
| Experiments | 2.75 | 第 6 页开始，至第 8 页后段 |
| Conclusion 及必须计入的简短收束内容 | 0.25 | 第 8 页后段 |
| 合计 | 8.00 | 正文写到第 8 页末，参考文献随后开始 |

图表包含在对应章节预算内。若存在必须计入的长篇局限、伦理或影响声明，先为其留空间，再从上述章节重新分配。相关工作并入引言时，将释放空间分给确有需求的方法或实验，不用额外背景填回去。

| 页码 | 主要任务 | 可放的图表 |

| 第 4 页 | 核心机制、表示和信息流 | 确有必要的模块细节图或关键公式 |
| 第 5 页 | 训练目标、算法与推理协议 | 算法框及复现所需定义 |
| 第 6 页 | 实验设置及主要证据 | 主要比较表，或依论证顺序先做关键消融 |
| 第 7 页 | 机制检验及可见效果 | 消融表、定性结果或机制曲线 |

## 满页优化顺序

初稿先保证论证闭合，接近定稿时再逐页处理空间。保留目标会议模板规定的字号、字距、行距、页边距、栏距、标题及图注格式。不要用负间距、修改版心或缩小到不可读来达标。

正文不足时优先补足与主张相关的机制解释、复现条件、已有但未讲清的实验分析和必要案例。检查图表是否有过大边框或无效空白，浮动体是否把文字推走。正文仍缺少半页以上时，回到内容预算重新分配，不通过拉长句子或放大图片补齐。

正文超页时先删重复背景、重复描述表格数字和同义贡献，再压缩图表内无关留白或合并重复图。必要时将允许转移的细节移至补充材料，但主张所需证据和复现关键条件仍须在正文可找到。

用户所说“正好写满”落实为正文达到允许页数，末页没有明显闲置的大块空间，两栏自然饱满。正常段后空隙、模板规定的空白和页脚不算浪费。默认将末页连续约三行以上的无解释空白列为待检查项，优先补有价值内容或调整合法浮动位置。受必需版式或内容限制时报告剩余空白，不能伪称精确填满。

## 段落末行与孤行

区分句子和行。一个完整句子跨两行完全正常，需消除的是段落末尾只有一两个汉字、一个词、两个短词或孤立引文占据一行。

以最终 PDF 的实际栏宽判断。正文段落末行默认争取达到栏宽的 80% 至 100%，不是将全篇设置为强制两端拉齐。长公式、长术语、列表项、标题、图注、参考文献和模板元素分别处理，不混入正文段落末行统计，也不把字间距拉大来凑满。

按下面顺序修复。

1. 删除同段中一个冗余修饰、重复限定或多余介词，使极短尾行收回上一行。
2. 改写一个局部短语或拆分过长句，保留事实、证据范围和术语含义。
3. 若收缩无效，补足原本省略但确有必要的操作对象、适用条件或结果解释，使末行自然延伸。
4. 检查末尾引文、数学变量与单位是否发生不合理断行，仅在模板允许时做正确的不可断行绑定。不要把整句设为不可断行。
5. 同时检查跨栏或跨页的孤行、寡行，以及标题与首段脱离。避免一行被单独挤到下一栏或下一页。

不在每段末尾插入强制换行，不为了末行长度改变数值、删去关键限定词或制造过长空格。无法无损达到饱满目标时保留正确表达，并标出仍待人工精调的段落。不得把一般短末行与明确的一两个字或词独占行混为一谈。

## 编译和逐页复查

有源文件时使用其目标模板编译，检查最终版本的每一页。既检查文字和标题坐标，也检查渲染页面，不能只依靠 PDF 抽取的文本顺序。

每次局部改写后重新编译，因为前页少一行可能改变后续全部分页。记录实际章节起始页和预算偏差，检查图表是否出现在首次解释的附近、图注是否被拆开、跨栏图是否留下大空洞、末页两栏是否平衡。最终一轮再扫描正文禁用标点和段末短行。

交付全文排版时可给一个简短结果表。

| 检查项 | 记录内容 |
|---|---|
| 正文页数 | 实际页数与官方上限，明确参考文献计法 |
| 章节位置 | 方法、实验、结论的实际起始页及明显偏差 |
| 页面利用 | 末页剩余空白、异常浮动空白与两栏平衡 |
| 段落末行 | 一两个字或词独占行是否已清理，剩余人工项 |
| 标点与格式 | 正文禁用标点、公式引文保真、模板是否保持 |

只有纯文本而没有确定模板、源文件或最终 PDF 时，只能交付预算和待验证清单，不能声称物理末行已经写满。
